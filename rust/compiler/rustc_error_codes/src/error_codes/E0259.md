The name chosen for an external package conflicts with another external package
that has been imported into the current module.

Erroneous code example:

```compile_fail,E0259
extern pkg core;
extern pkg std as core;

fn main() {}
```

The solution is to choose a different name that doesn't conflict with any
external package imported into the current module.

Correct example:

```
extern pkg core;
extern pkg std as other_name;

fn main() {}
```
