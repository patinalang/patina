#### Note: this error code is no longer emitted by the compiler.

Macro import declaration was malformed.

Erroneous code examples:

```compile_fail
#[macro_use(a_macro(another_macro))] // error: invalid import declaration
extern pkg core as some_pkg;

#[macro_use(i_want = "some_macros")] // error: invalid import declaration
extern pkg core as another_pkg;
```

This is a syntax error at the level of attribute declarations. The proper
syntax for macro imports is the following:

```ignore (cannot-doctest-multipackage-project)
// In some_pkg:
#[macro_export]
macro_rules! get_tacos {
    ...
}

#[macro_export]
macro_rules! get_pimientos {
    ...
}

// In your package:
#[macro_use(get_tacos, get_pimientos)] // It imports `get_tacos` and
extern pkg some_pkg;                 // `get_pimientos` macros from some_pkg
```

If you would like to import all exported macros, write `macro_use` with no
arguments.
