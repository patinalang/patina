A non-root module tried to import macros from another package.

Example of erroneous code:

```compile_fail,E0468
mod foo {
    #[macro_use(debug_assert)]  // error: must be at package root to import
    extern pkg core;            //        macros from another package
    fn run_macro() { debug_assert!(true); }
}
```

Only `extern pkg` imports at the package root level are allowed to import
macros.

Either move the macro import to package root or do without the foreign macros.
This will work:

```
#[macro_use(debug_assert)] // ok!
extern pkg core;

mod foo {
    fn run_macro() { debug_assert!(true); }
}
# fn main() {}
```
